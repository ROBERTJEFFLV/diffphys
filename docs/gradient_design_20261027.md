## 低速角度评分

原处理使用v/max(‖v‖,v_min)，速度不足时该向量缩短，错误方向或正交姿态可以通过减速减轻罚分。现在令s=‖v‖、a=max(s,v_min)、r=s/a、u=v/a，h为朝终点的单位方向，b为实际单位机体z轴。

方向误差平方改为：

```
||u-h||² + (1-r)(3+r)
```

固定方向d时，该式等于4−2r(1+d·h)，随速度降低不减。正交误差改为 `|u·b|+(1-r)`，等于1−r(1−|d·b|)，同样不能靠减速降低。在s≥v_min时，两者恢复原角度误差；零速时使用最大缺失方向误差，并保留朝目标方向的有限恢复梯度。平方根使用按dtype的机器epsilon作有限导数处理，并归一化使原角度通过边界不变。

## PASS与STOP组合

令φ(x)=log(1+max(0,x−1)²)。它在原容差内为0，零罚集合保持，远处大误差不会再产生原二次罚的巨大梯度。P为按原权重归一化的PASS罚分和，S为STOP七项约束的φ之和。当前组合为：

```
point_weight * [P + 2 log(1+S) + log(1+S/(1+P))]
```

对P的偏导为 `1−S/[(1+P)(1+P+S)]`，对S的偏导为 `2/(1+S)+1/(1+P+S)`，均为正。因此不能通过把穿点做差来逃避终点罚分，同时STOP梯度不会因P很大而完全消失。系数2是本轮离线对照选定的静态值。时间代理公式及权重3未改，没有增加生产反传次数或动态梯度归一化。

## 控制实验

五组均从旧运行第3062次更新的同一Actor出发，使用相同seed7、场景与噪声带，每组新建Adam，CUDA float32、512 TRAIN（128组×4）、256固定EVAL、H500、学习率0.001，各训练50次。初始Actor摘要和物理EVAL指标逐项相同。不同数值形状的总loss不能直接横比。

| 方案 | 2L进入率 | 硬PASS | 5秒末未越界 | 未穿点却低速靠近终点 |
|---|---:|---:|---:|---:|
| 原评分 | 29.30% | 0/256 | 91.02% | 25.39% |
| 仅角度修复 | 26.95% | 0/256 | 89.45% | 24.61% |
| 有序log、无独立STOP项 | 41.41% | 0/256 | 78.91% | 0.00% |
| 独立STOP权重1 | 48.44% | 1/256 | 82.81% | 2.34% |
| 选定：独立STOP权重2 | 50.78% | 1/256 | 87.89% | 11.33% |

最后一列是诊断指标：跑满H500且未越界、未进入测量PASS区域、最终速度<0.5 m/s、距STOP<0.5 m且在PASS球外，不是新任务阈值。选定方案末端STOP距离中位数0.3768 m，对照0.3765 m。完整任务成功率五组均为0；选定方案代理时间4.8758秒，对照4.8534秒，不能宣称已经更快完成任务。

另用同一冻结Actor、同一噪声带、128物理组各1个成员执行原生CUDA H500分量反传。每个分量都使用总梯度的分组裁剪乘数。原评分时间项与其余项的贡献范数比约0.00918%，选定方案约0.06640%，约7.23倍；选定方案STOP/PASS贡献范数比约0.305。此校准不是生产每组24成员的精确贡献比例，也不是Adam后步长分解。

CPU回归673通过、25个CUDA检查跳过；另外执行了本机RTX4060Ti上的64场景H8原生/编译前向与梯度对照，3e-4容差内一致。检查包含两种精度、低速径向单调性、零速/速度边界有限梯度、有限差分、PASS/STOP组合单调性与STOP下界、硬事件、原分组反传和既有回归。

原SOURCE_FILES仅 `plane_tasks.py` 与 `pass_stop.py` 改变。Actor、任务准备、GoalConfig、时间代理和点位生成的AST不变；原物理、噪声、BPTT、分组探针、裁剪及Adam代码逐字不变，未改冻结内核哈希。

生产接入只导入选定50步分支的Actor权重；目标函数与池规模变化后新建Adam，不伪装为旧任务精确续训。旧源码、检查点和全部实验分支保留。恢复3072场景持续训练至用户喊停，GUI与回放导出器跟随新目录。

这是一轮单seed、固定开发EVAL池的选型实验。进入率与减少绕过行为有所改善，未越界比例仍低于原评分，完整任务成功与更快完成尚未成立。结果不是独立泛化验证或部署许可。
