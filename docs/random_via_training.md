# 随机初态、中点与姿态训练

本任务以远端 `Agile-Flight-training@99dea6a` 为基线。用户要求从随机权重开始，按原规模在本机持续训练，直到用户喊停。新任务配置为 `configs/random_via_pass_stop.json`，参数入口为 `configs/random_via_flight.args`。

## 任务

- 起终点位置保持原配置：START=(-0.7B,0,0)，STOP=(0.7B,0,0)，原围栏每轴为±B，B=30L。
- 初始速度、姿态、角速度、电机状态及三个延迟速度历史槽保留原采样器的实际值；包含原约10%的引导初态。速度分量范围±2.5 m/s，角速度分量范围±2.2 rad/s，电机状态在[0,0.5)采样。原采样器与128组飞机不改。
- 中点中心在每轴[-(B−7L), B−7L]的立方体内随机生成，并拒绝与起点/终点重叠的布点。整个2L穿越球仍位于原围栏内。
- 倾角指机体推力轴与世界竖直轴的夹角。目标倾角在61°–119°采样，为原1°完整姿态容差预留余量，使合格姿态的倾角落在60°–120°内。方位角与绕推力轴的扭转也随机；仍要求匹配每行的完整目标姿态。
- 穿点速率下限固定1.5 m/s。低于下限计分，高于下限没有速度项惩罚；不约束为恒定速度向量。它是训练目标与成功判据，初期策略的动作不会被强行改写来保证达标。
- STOP位置/速度/姿态/角速度/加速度/角加速度/电机变化率要求、首次穿出切换、loss公式和权重保留。

初态随机化只恢复物理初态；公开START姿态和速度目标仍是原配置，不把真实初始姿态、速度或隐藏电机值额外传给Actor。已知上一命令仍为零占位；原测量噪声与10–30 ms速度延迟保留，外力和脉冲仍按三点任务关闭。

中点采样使用独立局部随机数，种子由任务种子、稳定场景ID和被固定起点替换掉的原随机出生位置派生。它不消耗训练全局随机数，不读取保留的电机/运动真值或传感器噪声来生成任务。固定EVAL和检查点回放可重建同一组目标；每批实际飞机和初态继续由原采样种子更新。

## 训练

GRUCell(69,64)→Linear(64,4)、3072 TRAIN场景、128个物理组且每组24成员、256固定EVAL、100 Hz、H500、完整BPTT、一次原生分组反传及原Adam保留。独立目录 `runs/pass_stop/random_via_from_scratch_seed7/` 中的 `continuous_train_response_control.py` 复用已有持续运行包装器，只取消更新数和时间预算，不改变训练函数。命令不含 `--resume` 或 `--init-checkpoint`。

```bash
TORCHINDUCTOR_COMPILE_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 PYTORCH_ALLOC_CONF=expandable_segments:True python runs/pass_stop/random_via_from_scratch_seed7/continuous_train_response_control.py @configs/random_via_flight.args
```

每次更新保存latest检查点，每10次更新运行固定EVAL；预算取消前，直接运行新args文件仍使用原50次/1800秒预算。进程PID、精确命令和源码摘要记录在运行目录。收到用户停止指令时，对该训练进程发送SIGTERM，训练器完成当前更新后保存Actor、Adam、RNG并退出。

这是新的任务/源码绑定，不能冒充冻结版本的精确续训；冻结检查点和哈希不改。数值故障仍按原事务逻辑保存失败证据、回滚并退出，不能把失败包装成持续正常训练。

## 验证边界

专项检查覆盖两种精度的随机初态保留、真实倾角和7L边界、1.5 m/s阈值、噪声/隐藏状态不干涉、行重排、逐行姿态loss及梯度、原生128组反传、回放目标和精确续训。3072训练场景及256固定EVAL场景通过静态准备；首批TRAIN目标倾角61.031°–118.991°，最小边界余量7.00176L。

这些点位检查不证明所有飞机对每个随机任务都能在5秒内完成。训练会如实记录失败和速率不足，没有降低60°–120°/1.5 m/s要求、替换弱机型或接入旧的保守俯仰证书。
